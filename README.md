# Sistema de Monitoramento de Tanque de Água

O projeto consiste no desenvolvimento de um sistema de monitoramento de tanque de água. O objetivo é permitir o acompanhamento do nível de água do tanque e do funcionamento da bomba, além de armazenar as medições realizadas.

## Tecnologias

As seguintes tecnologias são utilizadas no desenvolvimento do projeto:

- **Python:** linguagem utilizada no desenvolvimento do sistema.
- **SQLite:** banco de dados utilizado para armazenar as medições do tanque.
- **Git e GitHub:** utilizados para controle de versão e organização do projeto.
- **Tkinter:** será utilizado para a implementação da interface gráfica nas próximas etapas do projeto.

## Pré-requisitos e Instalação

Para executar o projeto, é necessário ter o **Python 3.x** instalado.

O projeto utiliza **SQLite** por meio do módulo `sqlite3` do Python.

### Passo a passo da instalação:

1. Clone este repositório para sua máquina:

```bash
git clone https://github.com/Leticia-web10/sistema-de-monitoramento-de-tanque-de-gua.git
```

2. Acesse a pasta do projeto:

```bash
cd sistema-de-monitoramento-de-tanque-de-gua
```
3.Execute o sistema:
```bash
python main.py
```

## Como usar

Atualmente, o sistema está sendo desenvolvido e executado pelo console.

O monitoramento realiza uma simulação do nível de água do tanque, gerando novas medições automaticamente.

### Fluxo prático de uso:

- Informe o nome do tanque;
- Informe a capacidade do tanque em litros;
- Inicie o monitoramento;
- Acompanhe o nível atual e a porcentagem de ocupação;
- Observe o funcionamento da bomba;
- Acompanhe o consumo de energia;
- As medições são armazenadas no banco de dados SQLite.

### Próximas funcionalidades

- Acompanhamento do consumo de energia da bomba;
- Implementação de uma interface para acompanhamento do consumo de energia da bomba;
- Consulta e visualização do histórico das medições;
- Implementação de uma interface para utilização do histórico de medições;
- Criação de uma barra de progresso para visualizar o nível de água do tanque;
- Criação de gráficos do nível de água e do consumo de energia;
- Implementação de alertas para situações anormais.
